# Ryan Week3 Project

## One Bird, Two Ways of Seeing

[Open the website](https://jiaming-bird-week-three.idealoasis4.chatgpt.site/)

A small interactive study of birds, interpretation and recorded movement.

Open `index.html` directly. No installation or API key is needed.

Use Observe, Messenger and Motion to switch views. Pause, replay, sampling and environment controls are included, along with three sketches and a reflection.

The flight and setting are illustrative, not measured animal behaviour.
